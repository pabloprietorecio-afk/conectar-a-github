# Catálogo objetivo de animación

No se reutiliza el catálogo actual como límite. Familias semánticas previstas:

- locomotion: idle variants, walk/jog/sprint, starts, stops, pivots, strafes
- ball control: receive ground/aerial, trap, shielding, first-touch variants
- passing: short/long, through ball, cross low/high, volley pass, weak-foot
- shooting: placed, power, chip, volley, header, bicycle/acrobatic variants
- dribbling: feints, cuts, body swerves, nutmeg attempt, stumble recovery
- defending: jockey, interception, standing/sliding tackle, block, clearance
- goalkeeper: set, shuffle, catch, parry, punch, dives by height/direction, recovery
- contact: shoulder duel, trip, fall directions, get-up variants
- emotion/context: miss, save reaction, protest, urgency, goal celebrations, defeat/win
- broadcast: tunnel, lineup, kickoff, substitution, injury, VAR, trophy/MVP hooks

Cada familia deberá contar con variaciones espejables o específicas de pie cuando proceda, blending y eventos sincronizados para balón/SFX/VFX.
